Connect Apple Health

Free Shortcuts on your iPhone. Sleep and Watch steps can arrive automatically when you open Messages. Your saved home-scale weight goes out when you choose to send it.

One-time iPhone setup required

Automatic sleep: finish the Shortcut you already built

Keep your Find Health Samples, Repeat, date formatting, Combine Text, and final Text actions. We will replace the clipboard ending with a direct connection to your private log.

  1. In Daily Health, open Settings → Apple Health → Connect iPhone → Create connection key. Keep that window open while copying the connection address and private key into Shortcuts. The key is shown once. Do not share the key or a Shortcut containing it.
  2. Open Apple’s Shortcuts app on your iPhone and edit the shortcut named Daily Health Sleep. Remove the final Copy to Clipboard and Show Alert actions. Keep the second Text action containing DAILY_HEALTH_SLEEP_V1, a line break, and the Combined Text variable.
  3. Below that second Text action, add URL. Paste the connection address copied from Daily Health. Do not add the private key to the address.
  4. Add Get Contents of URL below URL. Its input must be the URL action above it. Expand its options, change Method to POST, and choose JSON for Request Body. Add these three fields, each with type Text:
    Field nameValue
    keyPaste your private connection key.
    kindType sleep in lowercase.
    dataInsert the blue output of the second Text action—the one containing the header and Combined Text. Do not type the word Text.
  5. For the first test only, add Quick Look using the output of Get Contents of URL. Run the Shortcut once with your phone unlocked. Approve Sleep read access and the connection to Google's script address when asked. The result should contain "ok":true. In Daily Health → Settings → Apple Health, tap Refresh status and check the received time and the latest night's total. Existing manual values are kept.
  6. After that test succeeds, remove Quick Look. To be notified only of connection problems, add Get Dictionary Value, key ok, from the Get Contents of URL result. Add If that value is false (or 0), then Show Notification: “Daily Health sync needs attention. Check Settings → Apple Health.” Finish with End If. Do not add a daily Show Alert.
  7. Set the automatic trigger. In Shortcuts, open Automation → + → App → Choose → Messages → Done. Select Is Opened and Run Immediately. Tap Next and select Daily Health Sleep. If your version shows a blank automation instead, add Run Shortcut and choose Daily Health Sleep, then save. If your version puts automations inside the shortcut editor, use Edit → Automation → App and select the same Messages / Is Opened trigger.
  8. Switch to another app, then open Messages. This is the one-time trigger test. Check that Daily Health's received time advances. Afterward, normal use of Messages runs the import without a paste, review, or sync button.

Messages is only the trigger. No messages or contacts are read or sent. Apple Health can be unavailable while your phone is locked; an app-opening trigger runs during normal unlocked use. A network failure or delayed Watch sync can be caught up on a later opening. This is not a guarantee of a fixed-time background import.

Keep Find Health Samples set to the last 7 days with Limit off, and turn Include ISO 8601 Time on for both dates. If Shortcuts says it cannot share many Health items, open iPhone Settings → Apps → Shortcuts → Advanced and turn on Allow Sharing Large Amounts of Data.

Automatic sleep imports prefer Apple Watch sources. If Shortcuts leaves Source blank, Core, Deep, and REM stages can still sync; the app reports that the device name was unavailable. Awake and In Bed time are excluded, and broad Asleep records with no source are ignored. Steps still require a Watch source. Imports update recent days. The oldest part of the seven-day export is skipped because it may be incomplete. Repeated data does not add twice; shorter totals do not replace larger automatic totals. Manually entered, corrected, cleared, or deleted values stay protected. To stop incoming sleep or steps, turn that direction Off in Daily Health. Disconnect automatic imports revokes the key.

If your sleep preview ends each row with Core|, Deep|, or REM|, the blank Source is supported. Keep the final vertical bar and Source variable. After the one-time test, remove the temporary Quick Look preview so the Messages automation runs without stopping.

Automatic Watch steps

After sleep works, duplicate the Shortcut and name it Daily Health Steps. Change Find Health Samples to Step Count, the second Text header to DAILY_HEALTH_STEPS_V1, and the JSON kind value to steps. Keep the same address and key. If you have more than one Watch source, filter to your current Watch. Run a one-time test and then add a second Messages-opening automation for Daily Health Steps. Only Watch steps are imported, so totals may differ from Apple Health's combined count.

Building from scratch

Open Apple’s Shortcuts app on your iPhone. Create the shortcuts below with the exact names shown. These collection steps can be used for the automatic connection above. The clipboard ending below remains an optional manual fallback. This page does not install a Shortcut or automation on your phone.

Daily Health → Settings → Apple Health has separate On/Off choices. JEFIT importing is off in this free setup.

You approve Apple Health access on the phone: read Sleep and Steps for imports; read and write Weight for exports. Google sign-in continues to protect your private Sheet.

1. Daily Health Sleep

Tap + in Shortcuts and name it Daily Health Sleep. Add these actions in order.

  1. Find Health Samples: choose type Sleep, start date in the last 7 days, sort by Start Date, oldest first. Leave Limit off.
  2. Repeat with Each: use the Health Samples from the first action.
  3. Inside the repeat, add Format Date. Select the loop's Repeat Item, tap its blue bubble, and choose Start Date. Expand the action. Set Date Format to ISO 8601 and Include ISO 8601 Time to On. Add Set Variable immediately below it, name it Sleep Start, and select the output directly under this Format Date action as its input.
  4. Add another Format Date below Set Variable and above End Repeat. Select the loop's Repeat Item and choose End Date. Set ISO 8601 and turn Include ISO 8601 Time On. Add another Set Variable immediately below it, name it Sleep End, and select the output under this second Format Date action. Keep all four actions inside the repeat.
  5. Add a Text action inside the repeat with this one-line template. Replace each bracketed placeholder with the matching variable; do not leave the brackets in the result. 
    [Sleep Start]|[Sleep End]|[Repeat Item → Value]|[Repeat Item → Source]

    For Value and Source, insert Repeat Item, then tap that variable to select its property. If your version uses a separate Get Details of Health Samples action, use it to get those properties. Keep the three vertical bars between the values. Choose the sleep stage value, not the sample’s duration.

  6. After End Repeat, add Combine Text: combine Repeat Results with New Lines.
  7. Add a second Text action with the header below, a line break, and the Combined Text variable: 
    DAILY_HEALTH_SLEEP_V1
[Combined Text]
  8. Add Copy to Clipboard using that second Text. In its expanded options, turn Local Only on. Add Show Alert saying: “Sleep copied. Return to Daily Health → Settings → Apple Health → Paste sleep.”

Optional manual sleep test

Run the shortcut and allow Sleep access when prompted. Return to Daily Health, expand Manual import backup, then tap Paste sleep → Paste from clipboard → Review days. Compare the most recent night with Apple Health’s Time Asleep, then save the selected nights. Touch and hold the text box and choose Paste if the clipboard button is unavailable.

Awake and In Bed time are excluded. Overlapping sleep samples count once. Apple Watch samples are preferred when the Source label identifies them. Sessions are grouped across midnight and assigned to the day they end. Check the oldest night because a rolling date range can cut it short. If a total differs, cancel the review and check the Shortcut before saving.

Existing sleep starts unselected. Select an existing night only if you intend to replace its recorded duration. Only selected sleep totals go to your Sheet; the raw sample text stays in the browser until you close the import.

2. Daily Health Steps

Duplicate Daily Health Sleep in the Shortcuts app and rename the copy Daily Health Steps.

  1. In Find Health Samples, change Type from Sleep to Step Count (it may be labeled Steps). Keep the last 7 days and no sample limit. If you have used more than one Watch, filter Source to your current Watch.
  2. Keep the same Start Date, End Date, Value, and Source text template. Value is now the numeric step count.
  3. Change the header in the second Text action to DAILY_HEALTH_STEPS_V1.
  4. Change the final alert to: “Steps copied. Return to Daily Health → Settings → Apple Health → Paste steps.”

Run it, approve Step Count read access, then use Paste steps → Review days → Save selected days in Daily Health.

Only sources with Watch in their name are included. iPhone samples are excluded so they are not added on top of your Watch counts. Exact duplicate samples count once; conflicting overlaps or multiple Watch sources stop the import for review. Samples are assigned to the day their interval ends. Counts may differ from Health’s combined total. Today may be incomplete, and the oldest day may be cut short by the date range; import after a day ends for a full day.

3. Daily Health Weight

Create another shortcut named Daily Health Weight. Daily Health passes the saved value and date directly into this shortcut. You do not need to type the weight again.

  1. Add Get Dictionary from Input, and set its input to Shortcut Input. Rename its output Weight Entry.
  2. Add four Get Dictionary Value actions. Set each one’s dictionary to Weight Entry explicitly. Use these keys and rename the outputs:
    KeyOutput name
    kgWeight Kg
    timestampWeigh Time
    dayStartDay Start
    dayEndDay End
  3. Add Find Health Samples: type Weight, Start Date is between Day Start and Day End, Limit 1. Use the named variables for both dates. If a field needs a Date variable, use Get Dates from Input on its named value first.
  4. Add If: Health Samples has any value.
  5. Inside If, add Show Alert: “Apple Health already has a weight for this date. Nothing was added.”
  6. Inside Otherwise, add Log Health Sample: type Weight, value Weight Kg, unit kg, date Weigh Time. Keep kg even when Daily Health displays pounds; the app sends kilograms accurately.
  7. Still inside Otherwise, add Show Alert: “Weight saved to Apple Health.” Finish with End If.

First weight test

In Daily Health, save a home-scale weight. Go to Settings → Apple Health, choose its date, and tap Review weight to send → Open iPhone Shortcut. Review the Weight permissions on your phone and allow reading and writing. Confirm the entry in Apple Health.

Run the same export again. You should get the “already has a weight” message, with no duplicate. If you deny Weight read access, the shortcut cannot reliably check for existing entries; enable read access before using it.

Existing Apple Health weights are never automatically overwritten. If you corrected a weight after exporting, review that date in Apple Health yourself. Daily Health cannot see the Shortcut’s result; the success message in Shortcuts is the confirmation.

Daily use

Sleep and steps: after pairing and testing the Messages automations, use your phone normally; no daily paste is needed.
Weight: enter it in Daily Health, then review and send the saved weight.
Lifting: keep using the Lift Weights button and your workout grade.

Creating a key does not confirm a working connection. Finish the one-time phone tests and verify received timestamps. If Shortcuts uses different field names on your iOS version, stop at that step and we can adjust it together.
