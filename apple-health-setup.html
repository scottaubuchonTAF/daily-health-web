Connect Apple Health

Free Shortcuts on your iPhone. Sleep and Watch steps come in; your saved home-scale weight goes out. Run them when you choose.

One-time iPhone setup required

Before you begin

Open Apple’s Shortcuts app on your iPhone. Create the shortcuts below with the exact names shown. You will assemble them on your phone; this page does not install them. Start with sleep, then duplicate it for steps.

Daily Health → Settings → Apple Health has separate On/Off choices. Nothing syncs in the background. JEFIT importing is off in this free setup.

You approve Apple Health access on the phone: read Sleep and Steps for imports; read and write Weight for exports. Google sign-in continues to protect your private Sheet.

1. Daily Health Sleep

Tap + in Shortcuts and name it Daily Health Sleep. Add these actions in order.

  1. Find Health Samples: choose type Sleep, start date in the last 7 days, sort by Start Date, oldest first. Leave Limit off.
  2. Repeat with Each: use the Health Samples from the first action.
  3. Inside the repeat, add Format Date. Select Repeat Item, open its details, and choose Start Date. Set Date Format to ISO 8601. Rename this action’s output Sleep Start.
  4. Add another Format Date for Repeat Item’s End Date, also ISO 8601. Rename its output Sleep End.
  5. Add a Text action inside the repeat with this one-line template. Replace each bracketed placeholder with the matching variable; do not leave the brackets in the result. 
    [Sleep Start]|[Sleep End]|[Repeat Item → Value]|[Repeat Item → Source]

    For Value and Source, insert Repeat Item, then tap that variable to select its property. If your version uses a separate Get Details of Health Samples action, use it to get those properties. Keep the three vertical bars between the values. Choose the sleep stage value, not the sample’s duration.

  6. After End Repeat, add Combine Text: combine Repeat Results with New Lines.
  7. Add a second Text action with the header below, a line break, and the Combined Text variable: 
    DAILY_HEALTH_SLEEP_V1
[Combined Text]
  8. Add Copy to Clipboard using that second Text. In its expanded options, turn Local Only on. Add Show Alert saying: “Sleep copied. Return to Daily Health → Settings → Apple Health → Paste sleep.”

First sleep test

Run the shortcut and allow Sleep access when prompted. Return to Daily Health, tap Paste sleep → Paste from clipboard → Review nights. Compare the most recent night with Apple Health’s Time Asleep, then save the selected nights. Touch and hold the text box and choose Paste if the clipboard button is unavailable.

Awake and In Bed time are excluded. Overlapping sleep samples count once. Apple Watch samples are preferred when the Source label identifies them. Sessions are grouped across midnight and assigned to the day they end. Check the oldest night because a rolling date range can cut it short. If a total differs, cancel the review and check the Shortcut before saving.

Existing sleep starts unselected. Select an existing night only if you intend to replace its recorded duration. Only selected sleep totals go to your Sheet; the raw sample text stays in the browser until you close the import.

2. Daily Health Steps

Duplicate Daily Health Sleep in the Shortcuts app and rename the copy Daily Health Steps.

  1. In Find Health Samples, change Type from Sleep to Step Count (it may be labeled Steps). Keep the last 7 days and no sample limit. If you have used more than one Watch, filter Source to your current Watch.
  2. Keep the same Start Date, End Date, Value, and Source text template. Value is now the numeric step count.
  3. Change the header in the second Text action to DAILY_HEALTH_STEPS_V1.
  4. Change the final alert to: “Steps copied. Return to Daily Health → Settings → Apple Health → Paste steps.”

Run it, approve Step Count read access, then use Paste steps → Review days → Save selected days in Daily Health.

Only sources with Watch in their name are included. iPhone samples are excluded so they are not added on top of your Watch counts. Exact duplicate samples count once; conflicting overlaps or multiple Watch sources stop the import for review. Samples are assigned to the day their interval ends. Counts may differ from Health’s combined total. Today may be incomplete, and the oldest day may be cut short by the date range; import after a day ends for a full day.

3. Daily Health Weight

Create another shortcut named Daily Health Weight. Daily Health passes the saved value and date directly into this shortcut. You do not need to type the weight again.

  1. Add Get Dictionary from Input, and set its input to Shortcut Input. Rename its output Weight Entry.
  2. Add four Get Dictionary Value actions. Set each one’s dictionary to Weight Entry explicitly. Use these keys and rename the outputs:
    KeyOutput name
    kgWeight Kg
    timestampWeigh Time
    dayStartDay Start
    dayEndDay End
  3. Add Find Health Samples: type Weight, Start Date is between Day Start and Day End, Limit 1. Use the named variables for both dates. If a field needs a Date variable, use Get Dates from Input on its named value first.
  4. Add If: Health Samples has any value.
  5. Inside If, add Show Alert: “Apple Health already has a weight for this date. Nothing was added.”
  6. Inside Otherwise, add Log Health Sample: type Weight, value Weight Kg, unit kg, date Weigh Time. Keep kg even when Daily Health displays pounds; the app sends kilograms accurately.
  7. Still inside Otherwise, add Show Alert: “Weight saved to Apple Health.” Finish with End If.

First weight test

In Daily Health, save a home-scale weight. Go to Settings → Apple Health, choose its date, and tap Review weight to send → Open iPhone Shortcut. Review the Weight permissions on your phone and allow reading and writing. Confirm the entry in Apple Health.

Run the same export again. You should get the “already has a weight” message, with no duplicate. If you deny Weight read access, the shortcut cannot reliably check for existing entries; enable read access before using it.

Existing Apple Health weights are never automatically overwritten. If you corrected a weight after exporting, review that date in Apple Health yourself. Daily Health cannot see the Shortcut’s result; the success message in Shortcuts is the confirmation.

Daily use

Sleep and steps: run each import Shortcut, paste, review, save.
Weight: enter it in Daily Health, then review and send the saved weight.
Lifting: keep using the Lift Weights button and your workout grade.

This setup is ready for an iPhone test, not a confirmed connection until the phone tests pass. If Shortcuts uses different field names on your iOS version, stop at that step and we can adjust it together.
